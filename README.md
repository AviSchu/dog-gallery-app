# Our Project
כתבו אתר לצפייה בתמונות של כלבים. השתמשו ב-API של תמונות כלבים:
https://dog.ceo/dog-api

המשתמשים באתר יכולים להסתכל על תמונות הכלבים ולסמן את הכלבים שהם אהבו.
בדאטהבייס יישמר רישום של כל משתמש והכלבים שהוא אוהב.
המשתמשים יוכלו גם להסתכל על התמונות שהם סימנו שהם אוהבים, או על תמונות שמשתמשים אחרים סימנו שהם אוהבים

---

לכל הנתיבים יהיה את אותו תפריט עליון ובו כפתורי ניווט לדפים שונים באתר. בנוסף, אפשרות התחברות/התנתקות

---

הנתיבים שנרצה בשביל האתר:
/
דף ראשי
gallery/<breed>
גלריית תמונות של כלבים מהגזע breed. בגלריה יהיה תפריט צד ובו כל שמות הגזעים, כך שהמשתמש יוכל לבחור בגזע כדי לצפות בכלבים מהגזע הזה.
favorites
גלריית כל התמונות שאהבתי. על כל תמונה בגלרייה הזאת יהיה כפתור "Make profile picture" שתהפוך את התמונה לתמונת הפרופיל שלי.
users
רשימת כל המשתמשים. אנחנו נראה את שם המשתמש שלהם ותמונת הפרופיל
users/<user_id>
גלריית התמונות שהמשתמש user_id אהב. אני אוכל לסמן את התמונות גם כתמונות שאני אוהב.

---

דאטהבייס:
שני collections:
משתמשים (users) ובו לפחות התכונות הבאות:
-username (unique)
-profilePicture
תמונות אהובות (favorites) ובו לפחות התכונות הבאות:
-user_id
-url
הם המשתמש שאהב את התמונה וה-url של התמונה.
שימו לב! משתמש אחד לא אמור לאהוב את אותה התמונה פעמיים, או שהוא אוהב אותה או שלא.

---

על התחברות/התנתקות
בתפריט העליון יהיה input כדי להכניס שם משתמש וכפתור כדי להתחבר. כתבו את הקוד כך שאם לא קיים משתמש עם שם המשתמש שיוכנס ל-input, הוא יווצר באופן אוטומטי (הרשמה).

כל עוד המשתמש מחובר, ה-input והכפתור יוחלפו בכפתור אחר, התנתקות.

השתמשו ב-state בתוך הקומפוננטה App כדי לשמור את זהות המשתמש המחובר.

בסיום הפרויקט נרצה להרחיב את נושא ההתחברות וההרשמה וללמוד כיצד להוסיף סיסמה. בינתיים נדרש רק שם משתמש.
